# 🌍 世界観 ＆ ストーリー (World & Story)

> ### **「人間の国」と「獣の国」が共存する、西暦3000年の地球『フェアリー』**

各地を旅する自由な旅行者 **「はるちゃん」** が足を踏み入れたのは、獣人たちの領土である「獣の国」。
そこで彼女は、熊の村の頑固な村長 **「熊明（クマみょん）」** と遭遇することになります。

---

### 🏡 歓迎の宴、その裏に隠された陰謀
人間に対して良い印象を抱いていない クマみょんは、一見すると普通で居心地の良さそうな「ある民家」へと はるちゃんを案内します。しかしそこは…… **一度足を踏み入れば二度と出られない、旅人を監禁・監視するための家だったのです！**

村全体がお祝いの雰囲気で浮き足立つある夜、妙な気配（違和感）を察知した はるちゃんは、厳重な監視を潜り抜けて密かに脱出することを決意しますが……！

### 👤 1. キャラクター操作
> プレイヤーは**「はるちゃん」**を操り、モンスターの追撃から逃れるためにステージを駆け抜けます。

### 🦏 2. 障害物回避
> 前方から迫る回転障害物や、画面を埋め尽くす**サイの群れ**など、多彩な障害物を瞬発力で回避してください。

### ⚡ 3. 3段階のフェーズ進行
* マップには**総数3つのフェーズ**が仕込まれています。
* 次のフェーズに入るたびに、**障害物とモンスターの召喚ペースがどんどん速くなります。**
